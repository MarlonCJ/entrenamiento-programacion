# TypeScript

Empieza por la [introduccion a TypeScript](./INTRODUCCION.md) y sigue la [guia de instalacion](./INSTALACION.md).

## Ruta

Resuelve los archivos `01` a `24` en orden ascendente. Cada archivo presenta el concepto y la sintaxis TypeScript y contiene diez ejercicios sin resolver. Ejecuta desde la raiz, por ejemplo, `npx tsc typescript\01_variables_tipos.ts --target ES2020 --module commonjs --outDir typescript\dist` y luego `node typescript\dist\01_variables_tipos.js`.

Para evitar repetir el comando, puedes compilar el proyecto con `npx tsc -p typescript` despues de crear el `tsconfig.json` siguiendo la guia de instalacion.
