# Java

Empieza por la [introduccion a Java](./INTRODUCCION.md) y sigue la [guia de instalacion paso a paso](./INSTALACION.md) para configurar un JDK y Visual Studio Code en Windows.

## Temas y ejecucion

Sigue los archivos `Tema01` a `Tema24` en orden ascendente. Cubren variables, constantes, consola, conversion/validacion, operadores aritmeticos, asignacion, comparaciones/logica, operadores bit a bit y ternario, condicionales, bucles, cadenas, arreglos, colecciones, funciones, ambito, recursion, excepciones, archivos, modulos, POO, herencia/polimorfismo, pruebas/depuracion, algoritmos y estructuras de datos.

Desde la raiz compila y ejecuta, por ejemplo, `javac java\Tema01Variables.java` y `java -cp java Tema01Variables`, o usa `Tema17Excepciones` para practicar errores. Reemplaza el nombre de clase y archivo por el tema que quieras practicar. Cada archivo explica el tema y contiene diez problemas; escribe tus soluciones en `main` o en metodos auxiliares. El nombre de clase coincide con el archivo.
