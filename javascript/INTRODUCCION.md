# Introduccion a JavaScript

## Que es JavaScript

JavaScript es un lenguaje de programacion que se utiliza para dar comportamiento interactivo a paginas web. En el navegador puede responder a acciones, modificar la pagina y comunicarse con servicios. Con Node.js tambien se ejecuta fuera del navegador, por ejemplo desde la terminal, en servidores, herramientas de desarrollo y programas de consola.

## Para que se utiliza

- Crear interactividad en paginas web.
- Construir aplicaciones web del lado del servidor con Node.js.
- Desarrollar herramientas de linea de comandos y automatizaciones.
- Compartir codigo entre frontend y backend cuando una aplicacion lo necesita.

## Herramientas necesarias

1. **Node.js LTS**: ejecuta JavaScript fuera del navegador. Incluye `npm`, el gestor de paquetes.
2. **Visual Studio Code**: editor para escribir y revisar archivos `.js`.
3. **Terminal de Windows**: ejecuta Node.js y los ejercicios.
4. **ESLint** (extension opcional): ayuda a detectar errores y mantener reglas de estilo.

Estos ejercicios no necesitan paquetes de npm. La entrada/salida de consola del tema correspondiente usa modulos que vienen incluidos en Node.js.

## Como funciona un programa JavaScript

Guarda el codigo en un archivo `.js` y ejecutalo con Node. Por ejemplo:

```javascript
const nombre = "Ana";
console.log(`Hola, ${nombre}`);
```

Desde la raiz del proyecto ejecuta `node javascript\01_variables.js`. La carpeta contiene 24 temas numerados; empieza por el 01 y avanza en orden.
