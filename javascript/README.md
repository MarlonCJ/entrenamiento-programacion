# JavaScript

Empieza por la [introduccion a JavaScript](./INTRODUCCION.md) y sigue la [guia de instalacion paso a paso](./INSTALACION.md) para configurar Node.js y Visual Studio Code en Windows.

## Temas y ejecucion

Sigue los archivos `01` a `24` en orden ascendente. Cubren variables, constantes, consola, conversion/validacion, operadores aritmeticos, asignacion, comparaciones/logica, operadores bit a bit y ternario, condicionales, bucles, cadenas, arreglos, colecciones, funciones, ambito, recursion, excepciones, archivos, modulos, POO, herencia/polimorfismo, pruebas/depuracion, algoritmos y estructuras de datos.

Desde la raiz ejecuta, por ejemplo, `node javascript\01_variables.js` o `node javascript\17_excepciones.js`. Cambia el nombre por el tema que quieras practicar. Cada archivo explica el tema y contiene diez problemas; escribe tus soluciones en la zona de trabajo. No se requieren paquetes npm.
