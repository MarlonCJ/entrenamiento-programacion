# Escuela de fundamentos de programacion

Proyecto de practica para aprender los fundamentos en PHP, JavaScript, Python y Java.

## Como esta organizado

Cada lenguaje de programacion contiene **24 archivos, uno por tema**. SQL tiene su propia ruta de 24 temas, adaptada a bases de datos relacionales y consultas. Dentro de cada archivo encontraras:

1. Una explicacion del concepto y su sintaxis en ese lenguaje.
2. Ejemplos breves de sintaxis; son referencias, no las soluciones de los retos.
3. Diez problemas para que los resuelvas en la zona de trabajo al final del archivo.

6. `06_asignacion_unarios` — asignacion e incremento/decremento
7. `07_comparacion_logicos` — comparaciones y logica booleana
8. `08_bitwise_ternario_precedencia` — bit a bit, ternario y prioridad
9. `09_condicionales` — decisiones y ramas
10. `10_bucles` — repeticion e iteracion
11. `11_cadenas` — cadenas de texto
12. `12_arreglos` — arreglos y listas
13. `13_colecciones` — mapas, conjuntos y colecciones
14. `14_funciones` — funciones y metodos
15. `15_ambito_variables` — alcance y vida de variables
16. `16_recursion` — recursion y casos base
17. `17_excepciones` — excepciones y manejo de errores
18. `18_archivos` — lectura y escritura de archivos
19. `19_modulos` — modulos, importaciones y organizacion
20. `20_programacion_objetos` — clases, objetos y encapsulacion
21. `21_herencia_polimorfismo` — abstraccion, interfaces y polimorfismo
22. `22_pruebas_depurar` — pruebas y depuracion
23. `23_algoritmos_busqueda_ordenamiento` — busqueda y ordenamiento
24. `24_estructuras_datos` — pilas y colas

## Ruta recomendada

Avanza tema por tema. Para PHP, JavaScript, TypeScript, Python y Java puedes resolver el mismo tipo de fundamento y comparar la sintaxis. Para SQL, sigue su secuencia propia de consultas y modelado. Escribe tus pasos en pseudocodigo antes de programar y prueba cada solucion con varios datos.

Estudia los temas de cada lenguaje de programacion en orden ascendente. El tema 08 cubre operadores especializados; si aun no necesitas operaciones bit a bit, puedes leerlo despues de los temas principales. SQL tiene una secuencia distinta, adecuada a bases de datos, descrita en su propio README. Los archivos se nombran con numero para que el orden sea claro.
