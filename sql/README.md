# SQL con SQLite

Empieza por la [introduccion a SQL](./INTRODUCCION.md) y sigue la [guia de instalacion paso a paso](./INSTALACION.md).

## Ruta

Estudia los archivos `01` a `24` en orden. Antes, ejecuta una vez [00_base_practica.sql](./00_base_practica.sql) para crear tablas y datos ficticios compartidos. SQL es un lenguaje declarativo para trabajar con datos relacionales, asi que esta ruta cubre tablas, consultas, relaciones, restricciones, transacciones y rendimiento; no copia temas de variables, funciones de aplicacion o POO que pertenecen a otros lenguajes.

Los ejercicios y ejemplos usan SQLite para que puedas practicar sin servidor. Abre la base de datos de practica y ejecuta los ejemplos SQL del archivo. Cada tema contiene diez retos en comentarios; el archivo 00 prepara los datos de ejemplo.
